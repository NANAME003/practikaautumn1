Инструкции для Claude Code при работе с этим проектом.

## Как общаться

- Всегда отвечай **на русском языке**.
- Я студент, это мой **учебный проект** (практика). Мне важно понимать код и уметь его объяснить на защите.

## Главное правило: подсказывай, а не делай за меня

**Не меняй код проекта сам.** Когда я прошу что-то добавить, сделать или исправить:
- скажи, **какой файл** открыть и **в каком месте**;
- покажи, **что добавить или поменять** (фрагменты кода «было → стало»);
- объясни, **почему** так и как это работает.

Код я пишу сам. **Меняй файлы сам, только если я прямо скажу**: «сделай сам», «поменяй сам», «внеси изменения». Такое разрешение действует только на эту конкретную задачу.

Читать код, запускать сайт, сборку и проверки можно без разрешения: например, чтобы проверить мой код и найти ошибку.

## Как объяснять изменения

После каждого добавления или изменения кода обязательно расскажи:

1. **Какие файлы** изменены или созданы.
2. **Что поменялось**: покажи фрагменты кода «было → стало».
3. **Как это работает**: простыми словами, по шагам.
4. **Почему так**: почему выбран этот способ.

Новые понятия (хуки React, роутинг, props, json-server и т.п.) поясняй коротко и понятно.
Не делай больших изменений молча. Если задача большая, сначала коротко опиши план.

## О проекте

Сайт сервисного центра по ремонту и обслуживанию техники «ТехноСервис» (учебный проект).
Функционал: виды техники, услуги, заявки, статус ремонта.

**Текущий прогресс, что сделано и план следующего этапа: [`docs/PROGRESS.md`](docs/PROGRESS.md).** Обновляй этот файл после завершения каждого этапа.

**Делаем поэтапно, на каждом шаге реализуем только текущий этап**, остальное остаётся заглушками (`StubPage`):
1. Ребрендинг и главная (готово)
2. Каталог услуг (готово)
3. Форма заявки
4. Статус ремонта
5. Бэкенд на json-server (сохранение заявок, админка)

- **React 19** + **Vite**, точка входа `src/main.tsx`, роутинг в `src/App.tsx` (`react-router`)
- **Tailwind CSS** для стилей
- Данные услуг: `public/services.json` (загружается через `fetch`)
- Код компонентов в основном `.jsx`, корневые файлы `.tsx`

### Структура `src/`

- `components/`: части интерфейса (Header, Hero, DeviceTypes, Catalog, Benefits, Footer)
- `pages/`: страницы (HomePage, ServicesPage, StubPage, LoginPage, AdminPanel)
- `layouts/`: общий шаблон страницы (шапка + подвал)
- `hooks/`: свои хуки (`useServices` загружает услуги)
- `data/`: справочники (`deviceTypes.js`, виды техники)

### Команды

```bash
npm install        # установить зависимости
npm run dev        # запустить сайт (Vite)
npm run server     # запустить json-server на порту 3001
npm run build      # собрать проект
npm run lint       # проверить код линтером
```
