После каждого добавления или изменения кода обязательно расскажи:

1. **Какие файлы** изменены или созданы.
2. **Что поменялось**: покажи фрагменты кода «было → стало».
3. **Как это работает**: простыми словами, по шагам.
4. **Почему так**: почему выбран этот способ.

Новые понятия (хуки React, роутинг, props, json-server и т.п.) поясняй коротко и понятно.
Не делай больших изменений молча. Если задача большая, сначала коротко опиши план.

## О проекте

Интернет-магазин (учебный) на React.

- **React 19** + **Vite**, точка входа `src/main.tsx`, роутинг в `src/App.tsx` (`react-router`)
- **Tailwind CSS** для стилей
- **json-server** как простой бэкенд с данными о товарах (`products.json`)
- Код компонентов в основном `.jsx`, корневые файлы `.tsx`

### Структура `src/`

- `components/`: части интерфейса (Header, Hero, Categories, Catalog, Benefits, Footer)
- `pages/`: страницы (HomePage, ProductsPage, CartPage, LoginPage, AdminPanel)
- `layouts/`: общий шаблон страницы (шапка + подвал)
- `hooks/`: свои хуки (например `useProducts` для загрузки товаров)

### Команды

```bash
npm install        # установить зависимости
npm run dev        # запустить сайт (Vite)
npm run server     # запустить json-server на порту 3001
npm run build      # собрать проект
npm run lint       # проверить код линтером
```
